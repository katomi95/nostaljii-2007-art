# NOSTALJII 2007 — 画像版

▶ **遊ぶ: https://katomi95.github.io/nostaljii-2007-art/**

> 忘れようとしても、思い出せない。

2007年7月9日、豪華客船〈ノスタル爺号〉で爆発事件が起きる。犯人は「“あの日のアレ”を渡せ」と要求するが、本人も含めて誰も“アレ”が何なのか覚えていない。
90年代初頭の海外ミステリーADVの雰囲気で作ったパロディ短編です（プレイ時間15〜20分）。

## 遊び方
- クリック / タップ / スペースキーで会話を送る
- 尋問では「覚えている／覚えていない／覚えているふり」から態度を選ぶ
- 右上の **I-CAS** には主人公の本音が表示される
- 最後に赤か青のコードを切る。どちらだったかは、自分の記憶を信じてください

## この版について
元の SVG シルエット版の背景・人物・タイトル画を、画像生成AI（OpenAI）で描いたセピア調の一枚絵に差し替えた版です。
画像が読み込めない環境では、元の SVG が表示されます。

## 構成
- `index.html` — ゲーム本体（HTML / CSS / JavaScript、外部ライブラリなし）
- `assets/` — 背景・人物・タイトルの画像（JPEG）
- 効果音と環境音は Web Audio API で生成
